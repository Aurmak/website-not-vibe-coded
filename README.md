# website-not-vibe-coded

A Claude Code skill: rules for planning, writing, designing and building a marketing or product website so it reads as made by people, not generated.

The rules were learned on a real build and cover how to work with the site owner, what the site may claim, copy voice, visual design, page components, technical hygiene, the audits to run, and the final test.

## Install

Copy the `website-not-vibe-coded` folder into your skills folder:

```bash
git clone https://github.com/Aurmak/website-not-vibe-coded.git
cp -R website-not-vibe-coded/website-not-vibe-coded ~/.claude/skills/
```

Or, for one project only, into that project's `.claude/skills/` folder.

The skill loads on its own when you ask Claude Code for a website, landing page, marketing site or web copy, or to audit or redesign one. You can also invoke it with `/website-not-vibe-coded`.

For Claude on the web or in the desktop app, zip the `website-not-vibe-coded` folder and upload it under Settings, Capabilities, Skills.

## What's inside

- `website-not-vibe-coded/SKILL.md`: when the skill applies and how to use the rules at each stage, with two quick scans for copy and design.
- `website-not-vibe-coded/RULES.md`: the full rulebook.
